# 平台运维台

使用 `.env` 中的 `OPS_ACCOUNT` / `OPS_PASSWORD` 登录后进入运维台。运维身份只管理平台资源：它不能读取班级文件、会话或学生业务数据，对业务接口一律返回 404；「问 Agent」在运维台也不会检索班级资料。

左侧按职责分组，页面内部再按配置主题切换分区，避免在同一长页里寻找开关。

| 分组 | 页面 | 内容 |
| --- | --- | --- |
| 日常运营 | 班级与班管 | 开启班级、任命或更换班管、停用与归档班级 |
| 日常运营 | 模板库 | 评分方案模板的上架与下架 |
| 平台能力 | 邮件与通知 | 腾讯云 SES、SMTP、阿里云邮件推送与 Resend 的通道设置、通知策略、模板与投递日志 |
| 平台能力 | Agent 与知识库 | 模型连接、材料整理、知识问答与平台知识 |
| 平台能力 | 开关与阈值 | 访问与容量、频率限制、文件格式和登录页品牌 |
| 系统维护 | 组件健康 | API、PostgreSQL、Redis、Garage 与各 Worker 的状态 |
| 系统维护 | 队列与任务 | 积压、死信重投、Worker 心跳与定时任务 |
| 系统维护 | 备份与恢复 | 备份计划、保留期、异地目标与恢复演练 |
| 系统维护 | 部署与版本 | 版本、数据库角色、部署连接与安全参数的只读核对 |
| 系统维护 | 平台审计 | 平台配置操作的记录，不包含学生业务正文 |

## 运行时设置与部署配置

| 类型 | 修改位置 | 生效方式 |
| --- | --- | --- |
| 邮件通道、通知策略、模型连接与用途路由 | 对应运维页面 | 保存后由服务读取，无需重启 |
| 维护、注册、上传、频率与容量等运行开关 | 「开关与阈值」 | 在部署允许的范围内调整，无需重启 |
| 站点地址、可信代理、会话有效期、MCP、存储连接、备份挂载与加密密钥 | 部署环境配置 | 修改配置后重启或重新创建对应服务 |

网页中的运行设置保存在运维库；「部署与版本」展示当前进程加载的部署配置，不能在网页改写环境变量。部署值与可调运行值分开显示，便于判断该去哪个入口修改。

### 部署与版本：只读核对

除了版本、迁移与数据库角色，此页还展示：

- 站点公开地址及可信代理列表；
- Secure Cookie 状态、访问令牌与刷新令牌有效期；
- MCP 总开关与连接最长有效期；
- 对象存储的内部与公开端点、桶名、地域及 HTTPS 状态；
- 本地与离机备份目录、远程归档加密公钥是否配置；
- 邮件、AI、远程备份的凭据加密密钥是否就绪。

页面不显示数据库连接串、账号密码、访问密钥或密钥原文。「密钥就绪」只表示当前服务已加载对应加密密钥，不代表旧凭据一定能解密或通道已经配置正确；仍须在各能力页面完成自检。部署修改方法见[自托管部署](/deploy/self-hosting)，参数含义见[环境变量](/reference/environment)。

## 平台能力的设置分区

| 页面 | 分区 | 用途 |
| --- | --- | --- |
| 邮件与通知 | 发信通道 | 选择供应商、保存连接与发件人设置、管理凭据并发送自检邮件 |
| 邮件与通知 | 通知策略 | 业务邮件总开关、通知限额与静默时段 |
| 邮件与通知 | 邮件模板 | 腾讯云模板 ID，或 SMTP、阿里云、Resend 使用的本地模板说明 |
| 邮件与通知 | 投递日志 | 筛选投递记录、查看反馈与核对不确定结果 |
| Agent 与知识库 | 模型连接 | 供应商、凭据与用途路由 |
| Agent 与知识库 | 材料整理 | 材料识别与整理的开关和用量限制 |
| Agent 与知识库 | 知识问答 | 知识库、外发授权与问答额度 |
| Agent 与知识库 | 平台知识 | 维护平台产品说明，不读取班级资料 |
| 开关与阈值 | 访问与容量 | 平台开关及容量配置 |
| 开关与阈值 | 频率限制 | 请求速率与密码哈希并发 |
| 开关与阈值 | 文件格式 | 支持的材料格式 |
| 开关与阈值 | 登录页品牌 | 登录页标识设置 |

各通道凭据只展示是否已保存；不填写新值会保留已有凭据，清除使用独立操作。邮件设置与投递状态详见[邮件通知](/deploy/mail)，模型与知识库设置见[AI 与班级知识库](/deploy/ai)。

## 班级与班管

每个班级是一个隔离的租户。开启班级时填写班级名称与第一位班管的学号、姓名；班管随后用这组学号、姓名注册。班管账号需要恢复或更换时也在这里处理。归档班级会撤销该班级账号已创建的 MCP 连接。

## 开关与阈值

运维页可以热调整部分运行参数，无需重启：

- **维护模式**：暂停业务写入。
- **注册与上传**：全平台开关。
- **限流与并发**：在部署硬上限以内调整。硬上限来自环境变量 `API_RATE_LIMIT_PER_MINUTE`、`API_RATE_LIMIT_BURST` 与 `PASSWORD_HASH_CONCURRENCY`（每次 Argon2 约占 64 MiB 内存）。

公网入口仍建议在 Cloudflare 或 Ingress 层做边缘防护，应用层令牌桶只是最后一道闸。

## 队列与定时任务

后台工作通过 Redis Stream 投递给各 Worker，失败超过重试次数的消息进入死信，可在「队列与任务」重投。`worker:maintenance` 负责定时提醒、自动封存、审核时限、导出与临时文件过期清理等周期任务；各 Worker 定期写入心跳，停止上报会在「组件健康」显示。

各 Worker 的职责见[命令与服务](/reference/commands#后端子命令)。
