# 术语表

文档、界面和代码使用同一套术语。每条后面的「避免」列出容易混淆、不应使用的说法。

## 核心概念

**班级成员**：被纳入班级名单、可成为计分和结算对象的人。完成注册只增加登录能力，不改变成员身份。
避免：已注册用户

**实时成绩表**：根据已认定材料、基础分、扣分和专业成绩形成的当前成绩视图，同时显示未结事项。它随业务变化更新，不等待整表终审。
避免：终审快照、终审结果

**成绩确认**：学生对所看到的一版成绩的自愿核对记录。成绩或问题状态变化后需重新核对，确认不关闭申诉权，也不是结算条件。
避免：最终承诺、自动确认、强制确认

**单项审核**：两名审核人独立审查一条材料并给出认定意见；冲突按仲裁流程处理。
避免：整表终审

**封存**：停止个人新增和编辑材料的状态。封存不限制查看成绩、提出符合条件的申诉或核对当前成绩。
避免：终审开始

**结算**：班级在提交结束、单项定分、未结事项清零且专业成绩完整后生成的正式成绩记录。
避免：全员确认

**本人事项回避**：管理者不得终裁以自己为评分或举报对象的事项；班管本人的事项交给副班管。
避免：自我终裁

## 角色

| 术语 | 含义 |
| --- | --- |
| 班管 | 班级管理员，负责方案、名单、分发、仲裁与导出 |
| 综测小组 | 承担材料审核、复评与举报复核的成员 |
| 副班管 | 由班管从综测小组中任命，处理以班管本人为对象的事项；每班最多一名 |
| 运维 | 平台运维超管，只管理平台资源，不读取班级业务数据 |
| 共治成员 | 共治模式下主动加入、满 24 小时后生效的成员 |

## 流程

| 术语 | 含义 |
| --- | --- |
| 评分方案 | 分类、基础分、扣分、小项与计分规则的集合，发布后形成版本 |
| 分发 | 按确定的随机种子把材料派给两名审核人 |
| 仲裁 | 班管对双人冲突、申诉与异议作出的终裁 |
| 结算闸门 | 结算前必须满足的五个条件，全部满足后自动开启 |
| 公示 | 可选窗口，普通成员可查看已公开的计分条目与佐证原件 |
| 全系统封锁 | 可选窗口，晚于封存截止，封锁后任何人都不能修改 |
| 班级资料 | 班管发布的评定文件，也是班级知识 Agent 的检索来源 |

## 共治（测试版）

| 术语 | 含义 |
| --- | --- |
| 章程 | 启动表决时固定的精简或标准章程，决定评审人数与启动门槛 |
| 冻结选民 | 提案发布时确定的有效参与者名单，后续加入或退出不改变 |
| 随机评审 | 个人案件由随机抽取的成员独立判断，按多数形成结论 |

详见[班级共治](/guide/governance)。
