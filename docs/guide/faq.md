# 常见问题

## 在哪里交材料？

学生从左侧导航进入「提交材料」，提交后到「我的提交」查看状态。不要在 Agent 对话框里发送材料代替正式申报。步骤见[学生：提交与申诉](/guide/student)。

## 为什么没有按钮，或按钮不可用？

常见原因：

- 当前角色或视角不对应；
- 时间窗口未开放或已关闭；
- 记录已封存；
- 任务已完成或被改派；
- 方案尚未发布；
- 班管关闭了对应的功能开关，或运维开启了维护模式。

刷新后仍无法操作，把当前页面、记录编号和提示信息交给班管；不要让 Agent 猜测实时状态。

## 确认成绩后还能申诉吗？

可以。成绩确认只是对当前版本的自愿核对，不关闭申诉权，也不是结算条件。见[实时成绩与结算](/guide/scores-settlement#成绩确认)。

## 上传失败怎么办？

确认文件大小和格式在方案允许范围内、网络稳定，并等待上一份文件完成。显示「上传中」时不要重复提交。显示转换失败时，班管可在班级资料查看错误并重新处理。持续失败时记录文件类型、大小和页面提示，联系管理员。

## 注册时提示身份核对失败？

注册用名单中的学号和姓名核对。请班管在「班级成员」确认你的学号、姓名、身份和账号状态。

## 为什么 Agent 不可用或不引用资料？

班级知识 Agent 需要平台 AI、知识库、知识外发和本班第三方处理授权同时开启，并受每日额度限制。没有引用可能是资料没有命中、文件仍在转换、文档未对当前角色发布，或模型没有生成有效引用。涉及规则和状态时，请要求它检索资料，或直接联系班管确认。

## Agent 的回答能直接改变系统吗？

不能。Agent 的建议最多形成草稿或预填；提交、审核、方案发布、仲裁、结算和导出仍需有权限的用户在对应页面确认。通过 [MCP](/guide/agent) 接入的外部 Agent 同样受账号权限约束，管理类操作须由本人在网页批准。

## 班管能终裁自己的事项吗？

不能。以班管本人为评分或举报对象的事项由班管任命的副班管处理，见[任命副班管](/guide/class-admin#任命副班管)。
