# 账号与登录

## 注册

班级成员由班管预先导入名单。注册时先用**学号和姓名**核对名单，核对通过后设置密码即可登录，不要求绑定邮箱。核对失败时，请班管确认名单中的学号、姓名、身份和账号状态，不要重复创建相似账号。

完成注册只增加登录能力，不改变成员身份：未注册的在册成员同样参与计分、专业分、排名与结算，注册后可以查阅自己的既有记录。

## 登录与找回密码

使用学号或已绑定的邮箱，加上密码登录。忘记密码时在登录页找回；收不到邮件时先检查垃圾邮件，再确认账号已绑定并验证了可用邮箱。找回密码需要部署方已[启用邮件](/deploy/mail)。

## 账号设置

点击左下角自己的名字进入「账号设置」：

- **邮箱**：添加、验证、设为主邮箱或删除。删除前确保仍有可用的找回方式。
- **提醒**：按分类选择接收哪些通知，并设置每日汇总、静默与限额；每封通知邮件都附退订链接。
- **密码**：修改密码。改密会撤销该账号已创建的 [MCP 连接](/guide/agent)。
- **连接本地 Agent**：创建、查看与撤销临时 MCP 连接，并批准 Agent 准备的操作。

角色、班级归属、停用与解封由班管维护，用户不能自行提升角色。运维账号不使用这一页，其凭据在部署配置中管理。

## 切换视角

班管可以切换到学生或综测小组视角预览页面。这只是页面预览，不改变登录账号的真实角色或审计身份，也不能替代在「班级成员」中调整角色。共治模式下没有视角切换，所有成员使用同一个工作台。
