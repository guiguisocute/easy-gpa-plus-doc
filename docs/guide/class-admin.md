# 班级管理员

班管的工作按阶段划分：开学定方案和时间线，评定期间盯进度和仲裁，最后结算导表。侧栏也按这个顺序分为「班级」「评定设置」「评分」「导出与记录」四段。

## 首次配置

班级尚未开始正式计分时，初始化班管先选择**普通模式**或**共治模式**。**推荐选择普通模式**：它保留班管、小组、副班管的流程，选定后不再提供日常切换，本页介绍的都是普通模式的操作。

共治模式为测试版，尚未经过生产验证；它的准备与启动见[班级共治](/guide/governance)。

## 班级

- **班级看板**：审核进度、分数分布与待办统计。
- **审核明细**：逐项查看材料、审核轨迹，并直接处理。
- **班级成员**：导入名单、任命或调整角色、停用账号、解封。
- **班级资料**：上传评定文件并向全班发布，学生在「评定细则」查看；也是班级知识 Agent 的检索来源。

### 导入名单

在「班级成员」粘贴或选择 CSV，每行一条：

```text
2023211001,王一,student,女
2023211002,李二,group,男
```

四列依次为学号、姓名、身份、性别。身份可填 `student`、`group`、`class_admin`，省略时为学生。CSV 首行可以是 `sid,name,role,gender` 表头，文件不超过 1 MB。学号、姓名和身份只对尚未注册的成员生效；性别可以随时补充。

角色变更影响此后的权限，不会抹除以原角色产生的审计记录。

### 任命副班管

班管本人的冲突、申诉、小组提案和举报不能由自己终裁。请从已注册且已启用的综测小组成员中任命一名副班管，由其在「副班管仲裁」处理。每班最多一名，可以撤销或换人。

### 解封

学生封存后需要补交时，可在成员管理中解封并填写理由，理由记入审计。解封后仍须在材料开放期间提交；已有结算会失效，待业务事项完成后重新结算。

## 评定设置

- **方案编辑器**：维护分类、小项和计分规则，校验后发布为新版本，并可预览学生端表单。修改已发布方案前，先确认是否影响已有提交、审核或结算。结构见[评分方案](/guide/scoring-scheme)。
- **时间窗口**：材料开放、封存截止、全系统封锁、公示起止时间，以及审核确认时限和评优设置。
- **功能开关**：分别控制提交、修改、审核、申诉、仲裁、匿名举报和结算闸门。

修改时间窗口和功能开关不会发布新方案版本。

### 公示

公示窗口默认不设置。填写公示起止时间并保存后，本班普通成员在公示期间可以通过举报台展开计分条目，预览和下载已公开的佐证原件。未提交的材料、未公开的审核备注和匿名举报附件不公示；公示结束后普通成员不再获得下载地址。公示不会自动开启匿名举报提交。

## 评分

- **分发**：试算审核任务、检查冲突，再按确定的随机种子执行分配，把每条材料派给两名小组成员。改派与交接都会留下记录。
- **加分台**：按班级方案为单人或批量成员直接加分，可附佐证。
- **仲裁与申诉**：集中处理双人审核冲突、分类问题、学生申诉和需要终裁的异议。先查看两侧证据和规则再作决定。
- **处理历史**：按类型、学生、关键词和日期回看本人签发的处理记录。当时的裁定分保留原值，后续申诉或强制驳回不会覆盖旧记录。
- **专业素质分**：导入成绩数据参与总分合成与三好评定。导入后核对学号匹配、缺失记录和异常值。

## 导出与记录

- **导出中心**：生成汇总表、逐人明细和归档包，以及学院格式报表。任务在后台生成，完成前可稍后刷新。
- **审计日志**：谁看了什么、谁改了什么。

结算在满足条件后执行，详见[实时成绩与结算](/guide/scores-settlement)。

## 班级知识 Agent

启用前，班级必须确认第三方处理授权，平台也必须开启 AI、知识库和知识外发。班级资料上传后经过安全转换，状态为可检索或部分可检索时 Agent 才能读取正文；可见范围决定学生、小组和班管各自能否检索。撤销授权后，新的问答和 OCR 立即停止。运维无法查看班级文件。部署侧配置见 [AI 与班级知识库](/deploy/ai)。
