# 综测小组：审核

综测小组成员登录后落在「待办任务」。侧栏按判的对象分三段：材料审核 → 申诉与扣分 → 我的记录。

## 审核材料

「待办任务」列出分给自己的审核和申诉任务。只能处理系统分配且仍可处理的任务，不能通过修改地址或让 Agent 描述任务编号取得他人的任务。

在「初审工作台」结合申报内容、佐证、规则档位和当前方案作出认定：选择档位、填写认定分与理由，必要时提出分类建议。每条材料由两名审核人**背靠背**独立判断；在对方提交前看不到对方的结论，也不应打听或泄露。两人结论一致即定分，冲突交班管仲裁。

任务消失或按钮不可用，通常是任务已完成、被改派、时间窗口关闭或状态已变化，刷新列表并以页面为准。

## 申诉、扣分与举报

- **处理申诉**：复评派给自己的申诉，针对原审核结论和学生补充的理由作出判断。
- **扣分与异议**：记录基础分和扣分项，对定分提出异议；异议交班管终裁。
- **举报复核**：匿名举报由两人分头复核，看不到举报人身份。

分类建议不是最终改类，仍需有权限的人确认。

## 我的记录

- **我的审核量**：自己承担的任务数量、与人均的对比和规则速查。不代表可以自行领取未分配的任务。
- **历史审核**：本人的结论以及后来被改判的记录。另一名审核人尚未提交、条目未定分且审核仍开放时，可以「修改结论」；保存后旧结论和修改审计仍保留。两人都已提交、进入仲裁、定分、改派或审核关闭后不能再改。

## 副班管

班管不能终裁以自己为对象的事项。班管会从已注册且已启用的综测小组成员中任命一名**副班管**，副班管仍使用小组身份，侧栏多出「副班管仲裁」：复用仲裁台，只处理以班管本人为评分或举报对象的冲突、申诉、小组提案和举报，不提供班级设置或成员管理权限。

每班最多一名副班管。停用账号或转出综测小组会自动撤销任命；重置密码不影响任命。

## 使用 Agent

Agent 可以帮助查找班级规则、解释页面或形成审核预填，但不会替审核人提交正式结论。最终决定必须由本人在工作台核对后提交，并进入审计记录。
