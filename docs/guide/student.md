# 学生：提交与申诉

学生登录后直接落在「提交材料」。侧栏按使用顺序排列：看分 → 看进度 → 申诉 → 核对成绩。

## 提交材料

1. 在「提交材料」选择方案里的分类和具体小项。
2. 填写标题、数量或档位，以及必要说明；页面会按方案显示期望分。
3. 上传能证明该申报的佐证，等待上传完成。
4. 先保存草稿，核对小项、文字和附件。
5. 确认无误后正式提交。只有正式提交的记录才会进入审核。

表单由本班当前已发布的方案生成：能报哪些项目、需要什么佐证、如何计分，都以本班方案和「评定细则」中的班级文件为准。期望分只是预期，最终分数由审核认定并经后端结算器计算。

找不到项目或按钮不可用时，先确认材料开放时间和功能开关，这些由班管配置。

### AI 材料整理

平台开关、班级授权和模型配置都就绪时，可以用 AI 从图片或 PDF 中整理候选申报草稿。AI 只做识别和预填，自报分和档位都会标记「请核对」，不会自动正式提交；识别结果、分类和数量都需要本人逐项检查。

## 查看进度

「我的提交」按草稿、待审、已定分等状态列出记录。草稿尚未进入审核；已提交的记录能否撤回或修改取决于当前流程和时间窗口，页面没有对应按钮时不要用重复提交代替，请联系班管。

「综测总览」显示四项得分、总分和当前阶段。排名只在结算后出现，之前显示「尚未结算」。

## 申诉

对审核结果有异议时，从对应记录发起申诉，填写理由并补充佐证。申诉不是重新提交一条相同材料；复评与终裁会保留完整处理轨迹，可在「我的申诉」查看进度与结论。

## 实时成绩与核对

「我的成绩表」实时展示已认定材料、基础分、扣分和专业成绩，以及未结事项。核对后可以一键确认当前版本；成绩或问题状态变化后会提示重新核对。确认只是自愿记录，不阻塞结算，也不取消申诉权。详见[实时成绩与结算](/guide/scores-settlement)。

## 班级与举报台

- **评定细则**：班管发布的班级文件，可在线查看或下载原件。
- **举报台**：查看全班扣分并匿名举报。举报由两名综测小组成员分头复核，普通接口不暴露举报人身份。公示期间，普通成员还可在举报台展开计分条目，查看并下载已公开的佐证原件。

## 封存

材料提交截止后账号会被自动封存，也可以提前确认本人材料完成。封存后不能新增或编辑材料，但仍可查看成绩、提出符合条件的申诉和核对当前成绩。确需补交时由班管解封，解封理由会记入审计。
