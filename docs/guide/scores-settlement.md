# 实时成绩与结算

## 实时成绩表

实时成绩表根据已认定材料、基础分、扣分和专业成绩形成当前成绩，并同时列出未结事项。它随业务变化实时更新，不存在整表终审、整表问题或自动确认。

学生在「我的成绩表」逐项查看每一分的来源和处理进度；班管在「班级看板」查看分布与待办。排名只在结算后出现，之前显示「尚未结算」，系统不会拿当前提交去估算名次。

## 成绩确认

学生核对当前版本后可以一键确认，这只是自愿的核对记录：

- 成绩或问题状态变化后，页面提示重新核对；
- 确认不关闭申诉权；
- 确认不是结算条件，也没有定时确认或催办邮件。

## 时间窗口

| 窗口 | 作用 |
| --- | --- |
| 材料开放 | 学生可以提交与编辑材料 |
| 封存截止 | 截止后不再接收新材料，所有账号自动封存；审核、申诉、异议与仲裁照常进行 |
| 全系统封锁 | 可选，晚于封存截止。封锁后包括班管在内都不能修改，只保留查看与导出 |
| 公示 | 可选。公示期间普通成员可在举报台查看已公开的计分条目与佐证原件 |

**封存**只停止个人新增和编辑材料，不限制查看成绩、提出符合条件的申诉或核对当前成绩。解封后材料仍须在开放期间补交。

## 结算

结算生成本班的正式成绩记录。「班级看板」的**结算闸门**列出五个条件，全部满足后自动开启，之后在导出中心完成结算与导出：

1. 全员封存或提交窗口截止；
2. 单项全部定分；
3. 分类建议全部处理；
4. 无待终裁的冲突、申诉与异议；
5. 专业素质分已导入。

学生是否完成成绩确认不在检查范围内。闸门未开时，导出页只能预览。

普通模式下，确需提前上报时班管可以「强制开启结算」，跳过尚未满足的条件；必须填写理由，理由记入审计，综测小组和学生都能看到。共治模式没有这个入口。

结算后如有解封等变化，已有结算会失效，处理完成后重新结算。

### 排名与评优

- **排序**：依次比较总分、专业素质分、学号；学号只用于让重复结算结果稳定。
- **名次**：总分相同的同学名次相同。
- **奖学金档**：在「时间窗口」的评优设置中配置各档名称与人数占比。每档名额按「总人数 × 占比」独立四舍五入，再沿排序依次发放；同分由专业素质分分出先后，后一位顺延。
- **三好**：各项权重大于 0 的分类名次都在设定比例线以内。

这些结果写入结算快照，学生页面、班管预览和导出读取同一份数据，不在各处分别推算。

## 导出

导出中心生成汇总表、逐人明细、归档包和学院格式报表。报表模板位于主仓库 `backend/internal/exportjob/templates/`，可以按学校规则替换。
